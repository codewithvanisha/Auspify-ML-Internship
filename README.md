# Auspify-ML-Internship
Machine Learning projects completed during my Auspify Technologies internship.
## About

This repository contains the projects and tasks completed as part of my 4-week Machine Learning internship.

## Tasks

### Task 1 - Netflix Content Recommendation System
A content-based recommendation system that recommends similar Netflix titles using content-related features, TF-IDF, and cosine similarity.

### Task 2 - Content Type Prediction
Predicting whether a Netflix title is a Movie or TV Show using machine learning classification techniques.

### Task 3 - Netflix Audience Rating Classification
Predicting audience rating categories using classification models.

### Task 4 - Netflix Content Segmentation
Grouping Netflix titles into clusters using unsupervised machine learning.
