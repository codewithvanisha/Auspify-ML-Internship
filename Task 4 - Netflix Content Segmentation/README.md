**Internship:** Machine Learning Internship

## Project Overview

This project uses unsupervised machine learning to group Netflix titles based on similarities in their content features using the K-Means clustering algorithm.

## Dataset

The dataset contains 8,790 Netflix titles and 10 columns, including content type, title, country, release year, rating, duration, and genre information.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab

## Methodology

1. Loaded and explored the Netflix dataset.
2. Handled missing values and duplicate records.
3. Encoded categorical features and scaled numerical features.
4. Converted genre information into TF-IDF features.
5. Used the Elbow Method to examine cluster counts.
6. Applied K-Means clustering.
7. Visualized and analyzed the resulting clusters.

## Conclusion

This project demonstrates how unsupervised machine learning can be used to explore similarities among Netflix titles. The resulting clusters help identify patterns in content types, ratings, and genres.
